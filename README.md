# Biomedical Informatics — Learning Path & Playbook

Two companion tools for studying biomedical informatics and biological sciences.

## Contents
- **`learning-path`** — 12 visual micro-lessons across 3 stages, with an offline AI tutor in every card
- **`playbook'** — practical playbook with workflows and reference material

## Live site
https://narissa-pgm.github.io/biomed-learning-path/index.html

## Run locally
Open `index.html` in any modern browser. No build step, no dependencies.
